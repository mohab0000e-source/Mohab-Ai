# Mohab AI

واجهة أولية لتطبيق Android باللغة العربية باستخدام Flutter.

## بناء APK عبر GitHub Actions
1. ارفع محتويات هذا المشروع إلى مستودع GitHub جديد باسم `Mohab-AI`.
2. افتح تبويب Actions وفعّل GitHub Actions إذا طُلب منك ذلك.
3. شغّل `Build Mohab AI Android APK` عبر Run workflow.
4. بعد نجاح البناء افتح نتيجة التشغيل ونزّل Artifact باسم `Mohab-AI-Android-APK`.

## ملاحظات
- هذه النسخة تعرض واجهة المحادثة وتبديل الوضعين فقط، وتستخدم ردوداً تجريبية.
- لم يتم توصيل مزود ذكاء اصطناعي بعد.
- لا تضع مفاتيح API داخل تطبيق الهاتف. سنضيف خادماً وسيطاً آمناً في مرحلة الربط السحابي.
- سنضيف محرك التشغيل المحلي ونموذج GGUF بعد فحص توافق الهاتف ومساحة التخزين.
